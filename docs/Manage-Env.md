# 環境変数マネージャー

`Manage-Env.cmd` を実行すると、Windows PowerShell 5.1 の対話コンソールで起動します。追加パッケージや管理者権限は不要です。システムのプロパティを開かずに、レジストリの環境変数を直接読み書きします。PowerShell の実行と対象レジストリへのアクセスが許可されている環境で利用できます。

| キー | 操作 |
| --- | --- |
| ↑↓ / ホイール | 選択項目の移動 |
| Home / End / PgUp / PgDn | 先頭 / 末尾 / ページ移動 |
| Tab | ユーザー環境変数 / システム環境変数の切り替え |
| / | 変数名の部分一致検索 (大文字・小文字を区別しない) |
| Esc | 終了 (Q と同じ) |
| Enter | 値の詳細表示 |
| N / E / D | ユーザー環境変数の新規作成 / 編集 / 削除 |
| R | 保存値の再読み込み |
| Q | 終了 |

システム環境変数は表示専用です。ユーザー環境変数は変更操作ごとに変更前後の内容を表示し、[Y] キーを押すと保存します。編集画面では [Esc] キーで入力を破棄できます。テキスト入力は既存の値が入った状態から開始し、左右矢印キー、Home、End、Backspace、Delete によるカーソル移動と編集に対応しています。画面幅を超える長い値は、カーソル位置に合わせて横スクロールします。詳細表示画面や保存確認画面では長い値を折り返して表示するため、必要に応じてコンソールをスクロールして確認してください。

Enter キーの詳細表示画面では元の値をそのまま表示するほか、Path 変数またはセミコロンを含む値については、番号付きで1項目1行に整形した一覧も合わせて表示します。項目の順序・重複・変数参照はそのまま保持され、連続するセミコロンや末尾のセミコロンによる空要素は `(空項目)` と表示されます。この詳細表示は、ユーザー環境変数・システム環境変数の両方で利用できます。

ユーザー環境変数の Path を編集する場合は、項目がセミコロンで分割された専用の編集画面が表示されます。[A] で末尾への項目追加、[E] で選択項目の編集、[D] で削除、[U] / [J] で項目の上下移動が行えます。[S] で編集結果を確定して保存確認画面へ進み、[Esc] で Path の編集全体を破棄します。意図しない副作用を防ぐため、重複項目・空要素・末尾のセミコロンなどを自動で整理・削除することはありません。

環境変数の値は `%USERPROFILE%` などの変数参照を展開せずにそのまま表示・編集され、レジストリ上の既存の型 (`REG_SZ` / `REG_EXPAND_SZ`) を維持します。新規作成時は [S] (通常の文字列: `REG_SZ`) または [E] (変数参照を展開する文字列: `REG_EXPAND_SZ`) を選択します。空文字列の値としての保存と変数自体の削除は区別されます（空文字列を設定しても変数は削除されません）。文字列以外の型は表示のみに対応しています。変数名を変更する場合は、新しい名前で新規作成したあと、元の変数を削除してください。

保存の直前にレジストリの現在の値と比較し、編集開始後に他のプログラムによって値が変更されていた場合は上書きを防ぐため保存を中止します。ただし、値の比較と書き込みはアトミック（不可分）な処理ではないため、同じ変数を他のツールと同時に編集することは避けてください。

保存先は現在のユーザーのレジストリキー `HKEY_CURRENT_USER\Environment` です。保存後、他のウィンドウに対して `WM_SETTINGCHANGE` メッセージをブロードキャスト通知します。既に起動しているターミナルやアプリケーション、およびその子プロセスには変更が即座に反映されない場合があります。その場合はアプリケーションを再起動するか、必要に応じて Windows にサインインし直してください。システム環境変数とユーザー環境変数はそれぞれ独立して表示し、実行中プロセス向けに合成された環境変数は表示しません。レジストリへの保存に成功し、通知のみ失敗した場合は、保存済みであることとサインインし直しが必要な旨を表示します。
