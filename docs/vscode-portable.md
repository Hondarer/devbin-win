# devbin-win のポータブル版 Visual Studio Code

## インストール

`Manage-Bin.cmd` から VS Code を選択してインストールします。

| 内容 | 保存先 |
| --- | --- |
| VS Code 本体 | `%ProgramData%\%USERNAME%\devbin-win\bin\vscode` |
| 設定・拡張機能 | `%ProgramData%\%USERNAME%\data\vscode` |

導入処理はデータ ディレクトリを作成し、ユーザー環境変数 `VSCODE_PORTABLE` にそのパスを設定します。この設定はインストールのたびに行い、`VSCODE_PORTABLE` に別の値があっても上書きします。設定の反映には、インストール後にターミナルを開き直してください。

本体の下に `data` ディレクトリは作成しません。設定と拡張機能は常に製品フォルダーの外に置きます。

## 更新と削除

VS Code を終了し、コンポーネント マネージャーから再インストールします。本体とデータの保存先を分けているため、更新時にデータを退避する必要はありません。`data\vscode` の内容はそのまま維持します。

個別アンインストールでは `data\vscode` を保持し、`VSCODE_PORTABLE` を解除します。値が `data\vscode` 以外へ変更されている場合は、利用者の設定として残します。`data\vscode` を削除するのは、完全アンインストールで data の削除を選択した場合だけです。

## 運用上の制限

ZIP 版を使うため、更新はコンポーネント マネージャーから行います。ファイル関連付け、エクスプローラーのコンテキストメニューなどの OS 統合はこの処理では行いません。拡張機能が独自に保存するデータや外部ランタイムまで、この保存先へ集約されるわけではありません。

他のコンポーネントとの保存先の関係は [ユーザー設定・データの保存先](user-storage.md) を参照してください。
